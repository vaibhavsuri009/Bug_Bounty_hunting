# Verbose Authentication Header API Discovery

- What it is: Authentication errors can reveal hidden API paths or auth endpoints.
- Send a clearly invalid request to a candidate route in Burp Repeater.
- Inspect response headers as well as the body.
- Pay attention to `WWW-Authenticate` and other verbose authentication metadata.
- The book demonstrates an error revealing an `/api/auth` path.
- Use the disclosed path as a discovery lead, then validate it normally.
- False positive: a realm/path string can be generic documentation rather than a live endpoint.
- Edge case: gateways may inject authentication headers not generated by the backend.
- Remediation: return minimal authentication errors and avoid unnecessary internal path disclosure.
- Validation: confirm the finding manually against a clean baseline before treating it as exploitable.
