# Public API Directory OSINT

- What it is: API directories can reveal endpoints, versions, business purpose, auth models, SDKs, documentation, and changelogs.
- Search public API directories for the target organization/product.
- Record endpoint and developer-portal locations.
- Review version history and changelogs for retired functionality or security-relevant changes.
- Download public SDKs/source when available and inspect how authentication and requests are implemented.
- Use business-purpose information to prioritize high-risk functions such as payments or customer data.
- False positive: directory entries can be obsolete.
- Edge case: a listed API may be operated by a partner rather than the target.
- Remediation note: keep public listings accurate and retire stale endpoints.
- Validation: confirm the finding manually against a clean baseline before treating it as exploitable.
