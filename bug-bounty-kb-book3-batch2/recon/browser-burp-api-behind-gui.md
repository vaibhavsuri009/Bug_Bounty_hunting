# Discover APIs Behind a Web GUI with Burp

- What it is: Forwarding captured page-load traffic reveals API calls that are invisible in the browser interface.
- Browse the application normally and note URLs generated by actions.
- Enable Burp interception and refresh the page.
- Forward requests one by one while watching the GUI build.
- Flag paths containing patterns such as `/api/`, `/rest/`, admin routes, and JSON endpoints.
- Record method, parameters, headers, and the UI action associated with each call.
- False positive: static assets and telemetry endpoints are not business APIs.
- Edge case: some API calls fire only after login or specific feature interaction.
- Remediation: enforce server-side controls on every hidden/background endpoint.
