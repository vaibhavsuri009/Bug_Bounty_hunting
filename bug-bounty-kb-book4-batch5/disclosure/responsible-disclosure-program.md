# Responsible Disclosure Program

- What it is: A public disclosure policy gives researchers a safe, defined path to report vulnerabilities without legal ambiguity.
- Where to look / how to identify it:
  - Publish scope, allowed testing, prohibited actions, contact/submission method, and expected response timelines.
- Exploitation / test pattern:
  - Provide a clear report template and safe-harbor language.
- Tools + exact CLI syntax (if mentioned):
  - security.txt + disclosure webpage/ticketing.
- Common false-positive / WAF / edge-case notes:
  - Overly restrictive policies discourage useful reports.
  - Keep testing limited to systems, accounts, and data explicitly authorized for the engagement.
  - Confirm impact manually before reporting or chaining the result.
- Remediation: Define good-faith safe harbor, triage SLAs, and coordinated disclosure expectations.
