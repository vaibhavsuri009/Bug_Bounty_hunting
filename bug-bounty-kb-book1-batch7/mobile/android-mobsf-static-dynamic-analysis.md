# Android: MobSF Static and Dynamic Triage

- **What it is:** Automated mobile application testing framework for static and dynamic analysis.
- **Where useful:** Broad first-pass review of APK structure, code, permissions, and runtime behavior.
- **Workflow:** Analyze APK → review flagged components/secrets/configuration → manually verify high-value findings.
- **Strength:** Automates many repetitive mobile-analysis checks.
- **False positives:** Scanner output is only a lead; prove exploitability on a controlled device/emulator.
- **Edge case:** Dynamic checks require a compatible execution environment.
- **Remediation:** Fix confirmed client-side exposures and enforce sensitive controls on the server.
